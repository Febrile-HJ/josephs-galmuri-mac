# 조셉 갈무리 (Joseph's Galmuri) — 맥

캡처하고, 그 자리에서 화살표·말풍선·번호를 넣고, Return 한 번으로 붙여 넣는 맥 캡처 도구입니다. 조셉이 직접 만들어 지인에게 나눠 주는 앱이고, 설치 파일은 비밀번호로 잠겨 있습니다.

## 필요한 것

- Apple 실리콘(M 시리즈) 맥, macOS 14 이상
- 조셉에게 받은 설치 비밀번호

## 설치

1. **터미널**을 엽니다 (⌘ Space → "터미널").
2. 아래 한 줄을 붙여 넣고 Enter를 누릅니다.

   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Febrile-HJ/josephs-galmuri-mac/main/install.sh)"
   ```

3. 비밀번호 창이 뜨면 조셉에게 받은 비밀번호를 넣습니다.
4. 앱이 켜지면 메뉴 막대에 아이콘이 생깁니다. ⌘⇧2를 누르면 캡처가 시작됩니다.
5. 처음 캡처할 때 화면 기록 허용이 필요합니다. 앱이 띄우는 안내대로 시스템 설정 → 개인정보 보호 및 보안 → 「화면 및 시스템 오디오 녹음」에서 **Joseph's Galmuri**를 켭니다.

## 업데이트

새 판이 나오면 앱이 알려 줍니다. 메뉴 막대 아이콘 › **업데이트…**를 누르면 받아서 바꿔 끼우고 다시 켭니다. 단축키와 설정은 그대로입니다. 지금 쓰는 판은 메뉴 맨 위 줄에 보입니다.

설치 명령을 다시 실행해도 최신 판으로 바뀝니다.

## 알아 둘 것

- 이 앱은 Apple 공증을 받지 않았습니다. 조셉을 믿고 설치하는 앱입니다. 설치 명령과 앱 안 업데이트는 조셉 인증서로 서명된 앱인지 확인한 뒤에만 넣습니다.
- 캡처한 화면은 인터넷으로 보내지 않습니다. 앱이 인터넷에 접속하는 것은 새 판 확인(12시간마다, 이 저장소)과 새 판 받기뿐입니다.
- 옛 판은 휴지통으로 옮겨 둡니다.
- 지우려면: 메뉴 막대 아이콘 › 끝내기 → 응용 프로그램의 Joseph's Galmuri를 휴지통으로.
